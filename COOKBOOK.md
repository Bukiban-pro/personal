## Apocalypse Prep — When Everything Fails

| Failure Mode | Play |
|-------------|------|
| **AI provider down (all of them)** | You still have 649 UI components, dev-mode blueprint, and your brain. Open `research/`. Manual mode. You're still 10x, just slower. |
| **Credits exhausted mid-sprint** | Switch to `references/profiles/zero-budget.md`. Groq + DeepSeek free. Context drops to 8K. You lose polish, not capability. |
| **Corporate IT locked everything** | `references/profiles/locked-down.md`. Offline-first. No API keys. No cloud. Local LLM if available. Prepender works on any model. |
| **Git history corrupted** | `ai/` artifacts + `events.jsonl` + `runtime-status.json` = forensic trail. Rebuild from evidence. |
| **You're sick / 20% capacity** | `references/profiles/token-limited.md` + one-shot mode. The prepender thinks. You approve diffs. System works without the pilot at full capacity. |
| **Senior engineer hostile to your methods** | Inquisitor + Dev-Leroy prompts. Systemic analysis + brutal clarity. They can't argue with root cause evidence and concrete alternatives. |
