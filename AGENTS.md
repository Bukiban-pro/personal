# AGENTS.md - Boot Loader

**Before any task, read and adopt `BELT.md` as your operating system.**
This one file is the hot-path prep OS: roles, prompts, artifacts, acceptance checks, constraints.

`personal` stores architect tools for adapting workflows to other environments. A request to design or export an architecture stays ARCHITECT; it does not start a mission in this stash. Preserve the independent value of its learning prompts, research, examples, and specialist tools.

For goal execution architecture, use `references/prompts/jarvis-mission-execution.md`: an architect deployment recipe plus a portable runtime contract and mission/task templates. Inspect the target's existing authority, capabilities, and state before adapting it. Runtime mission records belong in the target workspace. JARVIS PRIME remains the separate full-stack/UX specialist prompt.

Boot: AGENTS.md -> BELT.md (load OS) -> SESSION.md (resume state) -> task.

Scripts: `prep` -> `task` -> `apply`. One dispatcher, one terminal, zero friction.

`references/archive/` and `research/` are cold memory, not hot boot dependencies. Do not delete them unless their unique value was extracted into a better artifact or a ledger explains why they are truly obsolete.
