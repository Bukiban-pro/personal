# cold-start

When you haven't touched the system in a week (sick, vacation, busy).
Target: re-enter in under 2 minutes.

## Steps

```
1. READ (30s)
   - Open references/prompts/core-philosophy.md. It contains all 7 profiles.
   - Pick one. Deploy. Nothing else to read.

2. CHECK SESSION (20s)
   - Does SESSION.md exist in project root?
   - Yes: read it. Is there an in-progress mission? Resume it.
   - No: you're starting fresh. Proceed to step 3.

3. PICK FORMULA (20s)
   - Situation: what are you doing? (ship/review/debug/learn/design)
   - Environment: what's available? (unlimited/locked-down/etc.)
   - Find the cell. Deploy the formula.

4. DEPLOY (30s)
   - core + profile + task format.
   - If using a new AI tool: load adaptive profile to self-classify.
   - If corp environment: load corp-sec profile to stay safe.

5. GO (20s)
   - You're in. First action: agent produces PLAN.md.
   - If you feel lost: state "I'm at 20%, guide me step by step."
```

## Checklist
- [ ] Read REFERENCES_FORMULA.md
- [ ] Check SESSION.md
- [ ] Formula selected
- [ ] Profile loaded
- [ ] First artifact in progress

## No Panic
- The system is designed to work at 20% capacity.
- If you skip a step, the system still works — just less efficiently.
- Worst case: paste core-philosophy.md and deploy from scratch.
