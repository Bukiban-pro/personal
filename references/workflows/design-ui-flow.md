# design-ui-flow

Formula: `ui-design + [profile] + task`

## Steps

```
1. LOAD
   - ui-design (agent-role-definitions.md — staff-level product designer)
   - profile (from REFERENCES_FORMULA.md matrix)
   - task: what's the user goal, what's the page, what constraints?

2. AUDIT (if improving existing)
   - Envy & Slop Audit:
     - Would senior designers respect this?
     - Would senior engineers see it as thoughtful?
     - Would it still feel strong and honest 2 years from now?
   - List anything that still looks like category boilerplate or AI template.

3. DESIGN
   - System & motion spec: tokens, layout, motion, framing, copy.
   - Flow walkthrough: happy path, edge cases, empty states, error states.
   - Onboarding & persuasion: how does the user discover and adopt this?
   - Experiments & audit: what would you A/B test?

4. SPEC
   - Per weakness: prescribe specific system-level adjustment (token, layout, motion, copy).
   - "Polish more" is banned. Every prescription must be concrete.

5. VERIFY
   - Principles check:
     - Clarity > Aesthetic
     - Detail is the product (states, motion, microcopy)
     - Ethical persuasion (no dark patterns)
     - Human > Aesthetic
```
