# Personal Archive

This directory is cold memory for `personal`.

It is not the hot boot path. BELT and `hands/prep.ps1` should be enough to start work fast. The archive exists because old prompts, doctrine, workflows, and research often contain reusable prompt DNA that should be mined before it is deleted.

## Rules

- Preserve unique patterns, prompts, examples, and field notes even when their facts are stale.
- Promote distilled patterns into BELT, scenario cards, checklists, or scripts when they become active doctrine.
- Delete only after extraction, confirmed duplication, secret risk, or explicit ledger entry.
- Treat old model/tool recommendations as historical until re-verified.

## Map

Use `RECOVERY_INDEX.md` before deciding whether an archived file is hot-path material, prompt/source material, stale reference, or safe-to-delete noise.
