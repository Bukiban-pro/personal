# research-topic

Formula: `learn + [profile] + task`

## Steps

```
1. LOAD
   - learn (universal-learning-os.md — 3-pass system)
   - profile (from REFERENCES_FORMULA.md matrix)
   - task: "Learn <topic>. I need to understand it enough to <apply/pass interview/build>."

2. PASS 1: ESSENCE
   - One-sentence explanation.
   - Top 3-5 core ideas in plain language.
   - "What problem does this solve?"

3. PASS 2: SYSTEM MAP
   - Key principles, categories/layers, how pieces connect.
   - 2-3 common mistakes and edge cases.
   - "When does this approach break?"

4. PASS 3: APPLICATION
   - 5-question recall quiz (no multiple choice).
   - One concrete application task (write code, solve problem, draft argument, design plan).
   - Compressed study note (10-15 lines).
   - Spaced review plan: revisit in 1, 3, 7, 14 days.

5. ARTIFACT
   - Compressed note added to relevant location (career/ or skills/).

6. TEACH (optional, for max retention)
   - Explain the topic in writing as if to a junior engineer.
   - Identify 3 questions a skeptical senior engineer would ask.
```

## Artifacts
- Compressed study note (10-15 lines)
- Spaced review schedule
- (Optional) written explanation + senior engineer Q&A
