# CARD: Token-Limited Emergency

**Formula:** core + token-limited (or inquisitor for review)

**Tool:** Any (budget-constrained)

**Prep (2 min):**
1. Paste the ONE file that matters.
2. Paste BELT.md (truncated to rules + artifact contracts only).
3. State the task in one sentence.

**Agent contract:**
- No greetings, no comments, no docstrings, no backticks, no alternatives.
- Output: the diff only. Or: the review only. Or: the fix only.
- 1 file max. 1K output max. One solution, perfect.
- If you need more: state exactly what you need and why.

**Acceptance:** Output is a diff, not a conversation. File is correct. No token waste.

**Rules:** Every token costs. One solution. Perfect. No fluff.
